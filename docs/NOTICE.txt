ORAC for Project Motor Racing — release candidate

ORAC is an independently developed, clean-room racing AI: no Project Motor Racing code,
data or file structure was copied into it. Project Motor Racing and its content remain
the property of their owners. ORAC changes the game in memory for one run; the installer's
file replacements are backed up and restored by Uninstall.bat.

Offline single-player only. Do not use ORAC in multiplayer.
