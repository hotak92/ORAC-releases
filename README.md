# ORAC for Project Motor Racing — downloads

ORAC is a free AI mod for Project Motor Racing. It replaces the AI in offline single-player sessions:
you drive your own car as usual, and ORAC drives every AI car — its speed plan, steering, braking, traffic and
full race strategy (fuel, tyres, repairs, pit stops).

## Download

Get the latest zip from the **[Releases](../../releases)** page (Assets → `ORAC-...zip`).

1. Keep Project Motor Racing on version **2.3.0.3** (a Steam update can break ORAC).
2. Close the game, extract the **whole** zip into a normal folder, run **`Install.bat`**.
3. Start the game with one of the ORAC launchers. `Uninstall.bat` restores the game.

Full instructions: [docs/README.md](docs/README.md) · changes: [docs/WHATS-NEW.md](docs/WHATS-NEW.md) ·
settings guide (F9 in game): [docs/TUNING.md](docs/TUNING.md) · [docs/NOTICE.txt](docs/NOTICE.txt)

## Help improve it

At [openracingai.com](https://openracingai.com) you can share ORAC's learned car data (with the site's share tool)
and the racing lines you record. Every player's data makes the AI better for everyone.

## Known issues

- Release candidate: expect rough edges.
- Some cars can still spin now and then when entering the pits on some tracks.
- Mod tracks are not supported yet. Mod cars need their performance envelopes: generate them with the bundled tools
  or download ones other players shared on openracingai.com.
- Hybrid deployment (LMDh, LMH, LMP1) is off in this release.
- Offline single-player only. Do not use ORAC in multiplayer.

The full list is in [docs/KNOWN ISSUES.md](docs/KNOWN%20ISSUES.md).

This repository holds the release packages and their documents only.
